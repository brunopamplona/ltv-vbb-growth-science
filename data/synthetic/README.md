# Synthetic Data

> ⚠️ **All data in this directory is 100% synthetic.**

No real subscriber data, no proprietary platform information, no client data of any kind is included in this repository.

## How data is generated

All datasets are programmatically generated by [`src/data/synthetic_generator.py`](../../src/data/synthetic_generator.py) using:

- **Fixed random seed (42)** for full reproducibility
- **Structural parameters** calibrated against published industry benchmarks for subscription streaming platforms (churn rates, LTV distributions, channel conversion rates)
- **Business rules** derived from the VBB framework described in the README (D7 classification thresholds, LTV multipliers, plan-level economics)

## Datasets

| Dataset | Generated by | Used in |
|---------|-------------|---------|
| `subscribers.csv` | `generate_subscribers()` | Notebooks 01, 02 |
| `retention_curves.csv` | `generate_retention_curves()` | Notebook 03 |
| `media_channels.csv` | `generate_media_channels()` | Notebook 06 |
| `ab_experiment.csv` | `generate_ab_experiment()` | Notebook 04 |
| `cohort_data.csv` | `generate_cohort_data()` | Notebook 05 |

## Regenerating data

```python
from src.data.synthetic_generator import (
    generate_subscribers,
    generate_retention_curves,
    generate_media_channels,
    generate_ab_experiment,
    generate_cohort_data,
)

df_subs = generate_subscribers(n=10000, seed=42)
df_subs.to_csv("data/synthetic/subscribers.csv", index=False)
```
